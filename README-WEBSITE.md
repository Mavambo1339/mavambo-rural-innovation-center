# Mavambo Rural Innovation Centre Website

This package is ready for GitHub Pages.

## Uploading to GitHub

1. Extract the ZIP file.
2. Open the extracted `mavambo-rural-innovation-center` folder.
3. On the GitHub **Upload files** page, drag **all files and the `assets` folder** into the upload box.
4. Wait for every file to finish uploading.
5. Under **Commit changes**, enter: `Upload complete Mavambo website`
6. Click **Commit changes**.

## Publish with GitHub Pages

1. Open the repository.
2. Click **Settings**.
3. Click **Pages** in the left menu.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Click **Save**.
7. Wait a few minutes. The website address should be:
   `https://mavambo1339.github.io/mavambo-rural-innovation-center/`

## Important edits before public launch

- Replace `assets/founder-placeholder.svg` with the official founder photograph.
- Replace project placeholder SVG images with real Mavambo photographs.
- Add the official telephone number and email in `contact.html` and the footer.
- In `contact.html`, replace `YOUR-EMAIL-ADDRESS` in the form action.
- Add verified organisational donation details in `donate.html`.
- Update project progress percentages as work advances.
